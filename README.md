## REST API для валют и обменных курсов. 

## Стек

- Python 3.10+
- http.server
- sqlite3
- pydantic 2

## Архитектура

- controller: принимает запрос, собирает DTO, вызывает сервисы
- service: бизнес-логика, выбор курса для обмена (прямой, обратный, кросс)
- dao: работа с базой
- dto: модели входящих и исходящих данных
- exceptions: ошибки и их превращение в код ответа
- router: выбор обработчика по методу и маршруту

## Запуск локально

    pip install -r requirements.txt
    python main.py

API поднимается на http://localhost:8000

Проверка:

    curl http://localhost:8000/currencies
